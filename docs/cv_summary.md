# CV Summary

## Project Summary

Research-oriented EEG processing project that documents an end-to-end workflow from raw signal conditioning through ICA-based artifact handling, ERP analysis, and time-frequency analysis. The repository emphasizes reproducible scientific computing, interpretable analysis outputs, and honest discussion of scope and limitations.

## CV Bullet Points

- Designed and documented an end-to-end EEG processing workflow in MATLAB covering detrending, band-limited filtering, event-locked epoching, bad-channel screening, ICA-based artifact rejection, average re-referencing, and conversion to analysis-ready epoched tensors.
- Implemented downstream ERP and continuous-wavelet time-frequency analyses on cleaned EEG, including within-subject and group-level summaries, scalp-topography visualization, and condition-wise interpretation of alpha-band and stimulus-locked responses.
- Structured the project as a reproducible research repository with modular analysis steps, saved intermediate datasets, figure validation utilities, and concise technical documentation suitable for academic and portfolio use.

## Skills Demonstrated

- EEG preprocessing and signal conditioning
- ICA-based artifact handling and channel interpolation workflows
- ERP analysis and time-frequency analysis
- MATLAB scientific computing and visualization
- Reproducible analysis organization and technical documentation
- Interpretation of physiological and artifactual EEG structure
